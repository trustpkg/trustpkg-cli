# Theme file format

The theme file has four required tables. Their names and the keys inside them
are fixed: do not add, remove, or rename tables or keys. Customize a theme by
changing the color values only.

The full-color tables accept `#RRGGBB` values. The limited-color tables accept
the 16 ANSI names: `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`,
`white`, and the corresponding `bright_` names. `background` can also be
`default` to preserve the terminal's configured background.

[`theme.GenerateThemeFile`](/tools/trustpkg-cli-forge/theming/generate):

unknown tables or keys, and invalid color values cause theme loading to return
an error.
