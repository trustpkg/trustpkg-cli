# Custom themes

Custom themes are optional. Without a custom theme file, Trustpkg CLI Forge
selects a built-in palette based on the detected terminal.

Use these guides to create a theme file, edit its colors, and load it in your
application:

- [Generate a theme file](/tools/trustpkg-cli-forge/theming/generate)
- [Theme file format](/tools/trustpkg-cli-forge/theming/format)
- [Load a custom theme](/tools/trustpkg-cli-forge/theming/use)

Custom themes change colors used by terminal components. They do not change
your application's command or business logic.
